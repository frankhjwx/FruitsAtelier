# FruitsAtelier v1.1.3

## What's new

- **Collab Mapping:** use a dockable panel to combine sections from other difficulties in the same project. Generate sections from bookmarks, assign sources, and synchronize objects and timing manually. Keep target hitsounds when desired, and inspect skipped sliders or spinners that cross section boundaries.
- **osu! editor links:** open `osu://edit/` timestamps and object selections in the active difficulty. Configure a fallback application for other osu! links in **Settings → osu! Links**. The time-jump dialog also accepts complete editor links.
- **FA-only difficulties:** create difficulties that stay in FruitsAtelier without generating or synchronizing Songs files. Change each difficulty's policy in **Song Setup → FA Settings**.
- **Remembered import choices:** choose whether imported sliders stay as Legacy Sliders or become FSliders, and save the answer for future imports in **Settings → General → Map Import**. Configure confirmation for suspected FA / Derandomizer exports there too.
- **Same-time placement:** enable **Settings → Experimental → Enable same-time object placements** to retain overlapping placements on both canvases.

## Fixes and improvements

- Recover simpler editable curves from confirmed compensated imports, including sparse samples and repeated sliders, with NM and HR playback validation. Preserve imported playback and randomization baselines through conversion, duplication, mode changes and saving.
- Preserve safely matched FSlider connections and complete unchanged Stream groups when choosing the entire osu! version during synchronization. Save a **Before full sync** recovery point before replacement.
- Copy hitsounds consistently across slider representations and preserve target event sounds when collaboration object-hitsound synchronization is disabled.
- Reclaim retired difficulty caches and reduce memory retained by dense imported slider paths.
- Keep canvas assist controls and flyouts usable on short canvases, improve coordinate readouts, and label FA-only difficulty tabs.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.1.3/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
