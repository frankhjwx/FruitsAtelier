# FruitsAtelier v1.0.1 Beta

## Editing and navigation

- Snap new objects horizontally to nearby objects without changing placement time. Object snapping is enabled by default; Configure DS controls the earlier/later search ranges from 0–4 beats, with defaults of 2 and 1 beats.
- Scale canvas X and Y independently with inline zoom controls, lock them together, and zoom both axes with Alt + wheel. Keep object sizes and hit regions capped at their 100% size, and preserve menu click priority over zoom controls.
- Enable optional 1/24, 1/32 and 1/48 snap divisions in settings, including Stream/Stack conversion and Ctrl + wheel navigation.
- Edit banana showers with Ctrl+F, using separate length and gap fractions, a full-map banana preview, and an option to split the result into separate objects. Zoom conversion previews with Alt + wheel.
- Show Stream/Stack fruits and internal combo starts on the object timeline. Add sample-bank selectors to the editing toolbar and configurable upper-timeline visibility and hover reveal.
- Improve measure markers, Distance Snap indicator dragging, SV/DPB controls, and live slider SV and maximum DS readouts.

## Backgrounds, compatibility and fixes

- Display map backgrounds across the mapping canvas with independent dim settings and a fading dim control. Drop images to replace a map background with confirmation, retaining the previous image file.
- Customize the X-axis grid colours and opacity, including Grid Snap subdivisions.
- Import Catch beatmaps in formats v7–v14 and stable-compatible lazer v128. Preserve v7 slider tick rules on export.
- Preserve effective and imported base SV during slider conversion; export generated upward sliders with Bezier red anchors.
- Keep the library responsive while opening projects, fix stacked banana hitsound amplification, respect testplay arrow bindings, and make testplay notice banners span the window.
- Require acknowledgement of the English notice before initial setup or opening beatmaps, with smooth Windows startup transitions.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.0.1/FruitsAtelier-1.0.1-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
