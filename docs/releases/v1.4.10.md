# FruitsAtelier v1.4.10

This release adds storyboard audio imports, native difficulty imports, and simpler synchronization review, with fixes for timing and sound editing.

## What's new

- **Storyboard audio in Hitsounding.** Drop one WAV, OGG or MP3 from a file manager or Audio Library onto SB Hitsound, with a snapped placement preview. Copy, cut, paste and undo retain the audio even after the original file is removed. Saving, FAZ export, version history and recovery copies preserve imported audio.
- **Import native difficulties.** Open `.catchdiff` or `.catchdiff.catchbackup` through Import difficulty in an existing project. Matching names offer an undoable overwrite or a numbered copy; the destination project supplies media.
- **Simplified synchronization review.** Choose simplified or individual resolution. Simplified review accepts other conflicts from osu! while keeping object changes, editable-authoring conflicts, all red timing changes and changes affecting playable events available for explicit review.
- **Timing clipboard across maps.** Copy rows in F6 and paste into Mapping or Hitsounding, including another map. Original timestamps and sound fields are retained; green points preserve coincident red points.
- **Movement strain navigation.** Scroll over the graph to navigate like the canvas, and use coloured bookmark lines to find marked sections.

## Fixes & improvements

- External-only object sound changes synchronize without unnecessary conflicts when local objects are unchanged. Compatible stream sound updates retain editable curves, and live authoring keeps the imported sounds on later saves.
- Exported green timing points retain their intended precedence at slider heads, including duplicate points at one timestamp.
- Cancelling synchronization back to Library restores browsing input.
- Sound drags retain the active Note based or Precise HS appearance, including duration and waveforms. Moving Audio Library files back into their current directory preserves selection and audition.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.10/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Use **Settings → Application updates → Check for updates** in an updater-enabled installation, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. Use the ZIP and its `.sha256` checksum for manual installation.

Mapset Verifier's corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip`.
