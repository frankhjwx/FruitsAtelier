# FruitsAtelier v1.2.3

## What's new

- **Mapset Verifier:** check exported snapshots of loaded difficulties directly in the editor, including unsaved changes. Open **Edit → Mapset Verifier** to browse General and difficulty reports, filter by severity, jump to issue timestamps, and copy grouped messages. Reports refresh automatically after edits while the panel is visible.
- **Optional timing alignment:** opening a difficulty can detect suspected one-millisecond object and timing-line offsets. Review the counts and align them in one undoable step, or keep the original timing.
- **Break synchronization review:** compare local and external break ranges in aligned columns and resolve individual differences independently.

## Fixes and improvements

- Drag spinner start and end boundaries independently on the canvas and object timeline.
- Correct eligible one-millisecond circle and spinner offsets on export without changing authoring data, and remove unused timing points while preserving slider samples.
- Stop audio promptly when closing the window, before waiting for background cleanup.
- Update the bundled runtime to .NET 10 and refresh SQLite and D-Bus dependencies to security-patched releases.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.2.3/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
