# FruitsAtelier v1.4.3

This release adds customizable keyboard shortcuts, shared Preview/Testplay mods, and a Catch object-gap readout.

## What's new

- **Custom keyboard shortcuts:** configure commands in Settings → Key Bindings, with independent Default and Lazer profiles, alternate bindings, search, conflict handling and per-command resets. Customized bindings are highlighted for easy identification.
- **Preview and Testplay mods:** share mod selections between Preview and Testplay, including difficulty, speed and visibility effects. Configure combinations from the Testplay panel and retain preferences across sessions.
- **Object gap:** select two complete objects on the Catch canvas to see the interval between them in the DS Indicator, including slider repeats and negative gaps for overlaps.
- **Fruit stack preference:** show or hide caught fruit sprites on the Testplay catcher from Appearance settings without changing judgments.

## Fixes and improvements

- Make Settings modal so covered editor and Library controls cannot receive input, and keep its size consistent across categories.
- Clarify shortcut descriptions and settings labels, and improve Testplay panel readability.
- Keep Mapping BPM flags smoothly clipped at timeline edges.
- Show object gaps correctly when selecting parent objects with Ctrl-click.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.3/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
