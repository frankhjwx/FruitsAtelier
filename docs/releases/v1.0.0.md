# FruitsAtelier v1.0.0 Beta

This is the first 1.0.0 Beta release.

## Editing and testplay

- Stack objects with the same start time in the object timeline, including slider bodies and markers, so overlapping objects can be selected and dragged separately.
- Set an independent testplay starting speed in **Settings → Testplay**. Returning to the editor restores its previous playback speed.
- Show testplay drain time in minutes and seconds, alongside the total seconds.
- Recalculate break boundaries after object and approach-rate edits.
- Keep playback following active object drags and show placement previews on the timeline. Held drags also start when playback or wheel navigation changes time.
- Select canvas objects by whether their centers fall inside the selection rectangle.

## Documentation and licensing

- Expand the English and Simplified Chinese READMEs and add Japanese and Korean editions, covering Catch tools, setup, and project workflows.
- Add the MIT license for original source code and acknowledgements for Catch community projects. Bundled third-party code and assets retain their existing licenses.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.0.0/FruitsAtelier-1.0.0-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
