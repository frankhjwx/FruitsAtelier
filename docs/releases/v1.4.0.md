# FruitsAtelier v1.4.0

This release introduces a dedicated Hitsounding workspace for editing, organizing and auditioning map samples, with live Timing Helper controls.

## What's new

- **Hitsounding workspace:** edit Normal, Whistle, Finish, Clap and storyboard sound lanes alongside note and timing intervals. Switch between Note based and Precise HS views, inspect waveforms, paint additions, and select, copy, paste or move sounds with undo/redo. Per-lane mute controls isolate sounds during Hitsounding playback.
- **Hitsound Library and Map Samplesets:** import audio files or folders, browse and organize a persistent sound library, audition one sound at a time, and drag samples onto map slots. Map sample replacements support undo and refresh preview audio.
- **Live Timing Helper:** edit existing timing points' offset, sample bank, index, volume and Kiai directly, with BPM and meter controls for red points. Browse nearby and affecting timing points without moving the playhead; use Jump to seek explicitly. Playback and timeline scrubbing resume following the current time.
- **Inherited timing editing:** create green points at snapped timestamps, drag individual or selected groups, and delete selected points in one undoable edit. Timing Helper sound edits preserve SV.

## Fixes and improvements

- Preserve event hitsound overrides when copying and pasting objects.
- Retain Alt+Left/Right bookmark navigation in lazer editing alongside the volume shortcuts.
- Improve stable-compatible slider timing precision and exported slider lengths across authoring paths.
- Publish linked `.osu` changes only on explicit save or export; opening or checking synchronization leaves local edits unpublished.
- Remove stale Library entries when their source directory disappears, and activate the selected difficulty before preparing slider imports.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.0/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
