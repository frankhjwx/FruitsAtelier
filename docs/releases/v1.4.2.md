# FruitsAtelier v1.4.2

This release expands Hitsounding with brush tools, per-track locks and optional Notes editing, and improves timing navigation and everyday editing.

## What's new

- **Hitsounding tools:** switch between Select and Draw, choose Soft/Normal/Drum brushes, and apply banks to selected notes or sounds with keyboard shortcuts. Hover tips explain each tool.
- **Per-track locks and Notes editing:** lock tracks against selection and editing. Unlock Notes to move, resize, copy or delete notes; Draw adds snapped circles. Note pastes create copies in empty intervals or transfer sounds to matching rhythms while preserving destination geometry.
- **Clearer timing tracks:** Hitsounding shows independently merged BPM, sampleset, volume and Kiai intervals. Mapping adds BPM flags, and the Timing waveform distinguishes measure lines from beats.
- **Timing navigation:** click the Hitsounding ruler to seek, or double-click a row in the F6 timing window to jump to its timestamp.
- **Data-only difficulty exports:** `.fad` exports contain native difficulty data without media; imports use resources in the receiving project. Older resource-bearing archives remain supported.

## Fixes and improvements

- Correct All Songs difficulty lists and counts for associated workspace projects.
- Keep Catch fruit placement and previews inside the playfield.
- Allow Legacy FSlider segment-boundary double-clicks with Slider Path hidden.
- Scroll time when dragging objects near the upper timeline's edges, retaining group spacing and one-step undo.
- Improve Hitsounding selection bank changes, Notes clipboard interactions and placement feedback.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.2/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
