# FruitsAtelier v1.2.1

## What's new

- **osu! discussions:** browse public reviews, general discussions and timeline threads from **Layout → Discussion**, with replies, resolution records, Markdown and images. Catch canvas markers and annotations connect discussions to their referenced objects; cached discussions remain available offline.
- **Discussion navigation and previews:** jump to timestamps, select objects from matching numbered references, copy post text and permalinks, and open author profiles. Preview images in the editor with zoom and pan.
- **Reverse collaboration sync:** copy a referencing difficulty's objects, section timing, optional hitsounds and song metadata back to the active difficulty. Successful synchronization automatically protects time outside the guest's referenced sections, with undo support.
- **Collaboration section protection:** lock time outside referenced sections, unlock it when needed, or remove notes outside collaboration sections. Locks persist per difficulty and appear in the canvases and timelines.

## Fixes and improvements

- Fix Catch slider placement replacing fruits within 2 ms of its head across X coordinates when same-time placement is disabled. Cancelling a draft or moving an existing slider preserves those fruits.
- Use `.fpt` for shared pattern packages while retaining legacy `.fap` drag import.
- Improve discussion link hover feedback, wrapped-link navigation and copied-link confirmation.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.2.1/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
