# FruitsAtelier v1.1.2

## What's new

- **Portable FA projects (.faz):** export a complete project with a playable OSZ, or native authoring data and resources only. Import independently, link to a matching local Songs project, or install a complete archive into Songs. Open archives by dropping them into the editor or through desktop file associations.
- **Selection rotation:** use **Ctrl+Shift+R** for a live rotation preview with angle, direction and origin controls. Confirm as one undo step or cancel to restore the selection. Catch rotation preserves the original time interval.
- **Independent slider endpoint snapping:** choose separate start and end grids in Slider Inspector, including automatic nearest-grid snapping. The global beat grid now includes **1/10** and **1/11**.
- **Clearer slider controls:** collapse Inspector sections for timing, conversion, droplets and structure. Inspect actual endpoint beat fractions beside sliders and in the Inspector.
- **Direct difficulty opening:** click a difficulty in the library detail list to open it directly. High-star icons and rating text have improved contrast.

## Fixes and improvements

- Compare synchronized sliders by their playable Catch events while retaining equivalent native curves. Review timing attributes and changed fruit, droplet and banana positions side by side.
- Publish confirmed synchronization resolutions to linked `.osu` files and preserve accepted timing choices across later external edits. FAZ links review differences before establishing a baseline.
- Keep unsaved edits intact during background synchronization, with Save / Discard / Cancel when leaving a dirty project.
- Improve movement previews and hide osu! movement connections across gaps longer than two beats. Convert osu! slider paths into individual notes with **Ctrl+Shift+F**.
- Use fewer anchors when editing circular arcs while preserving trajectory accuracy. Restore derandomized drawing defaults for imported maps and older projects.
- Open FAZ import choices without waiting for library scans, reclaim abandoned archive staging, and make recovery backups optional when deleting a local project.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.1.2/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
