# FruitsAtelier v1.0.3 Beta

## Experimental lazer editing

- Enable **Settings → Experimental → lazer editing** for an alternative Compose canvas with an automatic catcher, a fixed judgement line, gameplay visibility brackets and movement guides. Switching modes preserves map content and undo history.
- Zoom around the catch line with Alt+wheel, unlock independent X/Y scaling up to 200%, and pan horizontally with the middle mouse button. The upper timeline has its own animated zoom. Mapping view preferences remain separate.
- Choose **Follow mode**, **On** or **Off** for skin hit lighting across the editing canvas, Catch Preview and testplay.

## Distance and speed presets

- Choose map-specific **Distance Snap presets** or **Global speed presets** in either editing mode. Each mode remembers its choice across maps and restarts. Speed presets include fixed 0.5 and 1.0 px/ms entries and up to eight custom values.
- Use movement-coloured guides with optional visibility and collinear snapping in both preset systems. Movement Analysis labels follow the selected DS or speed units; Slider Inspector shows Max DS or Peak horizontal speed accordingly.
- Placement movement previews account for the Break ranges that the new object would produce without changing the map during hover.

## Slider droplet controls

- Set selected ordinary FSliders to **Follow map**, **Derandomize** or **Randomize** directly in Slider Inspector, including mixed selections and undo. Reset manual droplet adjustments independently of the mode.
- Use **Droplet Settings** for the current difficulty's default mode, strength, seed and NM/HR compensation target. Existing project sliders retain their previous output until edited; saved projects with per-slider modes require this version or newer.
- Fix immediate droplet randomization controls and Inspector state updates.

## Interface and workflow

- Adjust **Settings → Appearance → UI scale** from 50% to 200% in 25% steps, applying without a restart.
- Resize the upper object timeline and bottom overview from 50% to 100% of their original heights. Heights persist as view preferences. Playback controls and timestamps use a more compact layout, with a playback-speed selector beside Volume.
- Restore editor function-key shortcuts and use **- / =** for canvas stretching.
- Offer Songs export once per workspace project, and reuse the loaded playback duration for AiMod audio-length checks.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.0.3/FruitsAtelier-1.0.3-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
