# FruitsAtelier v0.9.7

## Setup and display

- A five-step first-time setup guide configures folders, language, skin, volume, Slider Droplets and testplay. Existing users see the guide when upgrading; completing it saves the choices and opens the library.
- Preview skin graphics and audition music and hitsounds during setup. Saved volume values are preserved; missing values default to 50%.
- Toggle fullscreen with **Alt+Enter** or **Settings → General → Fullscreen**. The preference is saved across launches on Windows and macOS.
- Simplified Settings text and improved spacing in Stream and Stack controls.

## Library and editing

- Mark library maps as favourites and filter the library to show them. Favourite choices persist across restarts.
- Selected slider droplets retain priority over bounding-box movement when dragging.

## Testplay

- Press **Ctrl+R** to retry from the session's start, retaining autoplay and speed, while running or paused.
- During autoplay, adjust speed with **Ctrl+Up/Down** in 25 percentage-point steps or **Ctrl+Shift+Up/Down** in 5-point steps, within 10%–150%.
- Testplay stays visible when replacing the session during a retry.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.7/FruitsAtelier-0.9.7-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
