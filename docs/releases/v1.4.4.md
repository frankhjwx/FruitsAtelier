# FruitsAtelier v1.4.4

This release adds a Media dock, background-based colour palettes, and new timing and volume tools for Hitsounding.

## What's new

- **Media dock:** assign backgrounds and videos from files or drag and drop, browse optional subfolders with a draggable scrollbar, adjust video offsets, and synchronize media across project difficulties with undo support.
- **Background colour palettes:** generate 3–8 combo colours from the current background, preview the swatches, and apply them to the active difficulty.
- **Hitsounding timing tools:** copy selected red and green timing points between difficulties at their original timestamps, replacing destination points at those timestamps in one undo step. Add an inherited timing point at the playhead with the configurable **5** shortcut.
- **Volume ramps:** select two adjacent green timing points with different volumes and matching timing/sample properties to generate a beat-spaced volume transition.
- **Mapping Canvas selector:** switch between osu!Legacy and Catch directly above the sample-bank controls.

## Fixes and improvements

- Show Library difficulty names while uncached star ratings are calculated, prioritize the selected set, sort completed ratings from highest to lowest, and display scan/rating progress.
- Apply Timing Helper sample settings to the affecting timing line, improve volume stepping and scrolling, and highlight the sample bank of selected sounds.
- Improve Hitsounding rhythm paste targeting and rounding tolerance, and clarify track mute and lock states.
- Show configured shortcuts in tool hints and menus.
- Preserve unrelated editor preferences when applying Settings, and remove unused spacing beside an empty left dock.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.4/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
