# FruitsAtelier v1.2.2

## What's new

- **Embedded osu! Web:** right-click the Discussion dock tab to switch between the native **Read only** reader and the official **osu! Web** page. The embedded browser retains its session across restarts, and website timestamp links seek and select notes in the editor.
- **Canvas annotation control:** show or hide discussion cards and markers with the canvas button while keeping note-interval highlights visible. The preference is saved for both Discussion modes.
- **Unified object actions:** right-click objects in lazer editing, long-press, or press **Shift+F** to access the same selection-aware editing and conversion actions on the Catch canvas and object timeline.

## Fixes and improvements

- Move deleted local projects and unused managed resources to the system Recycle Bin / Trash when no recovery backup is retained. Source beatmaps are kept.
- Restore exported slider velocity at the next unedited slider that needs it, avoiding unnecessary restoration points while preserving slider timing.
- Improve embedded browser docking, overlays and input focus; timestamp jumps return keyboard focus to the editor.
- Let discussion cards without internal scrolling pass wheel input to the canvas, and keep upvote icons neutral regardless of vote count.
- Combine browser data controls and protocol settings under **Settings → osu! Links & Web**, including an option to clear embedded browser cookies and local data.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.2.2/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
