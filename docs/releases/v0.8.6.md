# FruitsAtelier v0.8.6

## What's new

- **Slider editing:** select and drag individual fruits, droplets, and tiny droplets on an FSlider. Distance Snap applies to slider drawing, shape edits, and selected slider events, while Grid Snap applies to event dragging when Distance Snap is off. Converted sliders better preserve randomized droplet positions.
- **Note snapping:** the editor recognizes nearby beat subdivisions when editing notes, including sixth-beat patterns.
- **Appearance:** choose separate Stand, Walk, Dash, and HDash colours for movement indicators. The editor also reads hyperdash colours from the active skin's `CatchTheBeat` section.
- **Library:** project actions include exporting an OSZ archive. Testplay continues when the editor loses focus.

## Fixes and improvements

- Movement Analysis remains visible during Kiai sections and avoids complete connections across breaks.
- Slider tick samples update after timing-point changes. Fractional slider endpoint drags and break recalculation after note removal are corrected.
- New Combo labels stay attached to their fruits when flags change.
- Stable update checks recover release assets when GitHub's release list omits them.
- Slider anchor dragging and export feedback are more responsive.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.8.6/FruitsAtelier-0.8.6-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
