# FruitsAtelier v1.2.0

## What's new

- **Pattern Gallery:** capture selected objects as reusable patterns, browse skin-rendered previews, and drag patterns onto the Catch canvas. Placement follows the destination beat grid and BPM, with a choice to keep horizontal spacing or preserve horizontal speed, and supports undo.
- **Pattern organization and sharing:** organize patterns in folders, search names and source metadata, and filter by coloured tags. Move, copy, merge and export selections or folders; share `.fpt` packages and import them into new or existing folders, including by dropping a package into the editor.
- **Pattern editing and source navigation:** edit a pattern in an isolated workspace, rename it from its preview, or return to its original map. Scroll and zoom enlarged previews, resize cards, and select ranges across the gallery.
- **My Maps:** filter the Library by your configured mapper usernames and optionally disable standard-mode map scanning in General settings.

## Fixes and improvements

- Restore cached Library pages, star ratings and thumbnails across restarts, with independent caches for tabs and FA/osu! Collections. Improve substring searches and input scheduling.
- Defer project history retention to idle Library maintenance to reduce save-time work.
- Allow deleting complete sliders across canvases while retaining the representation-specific editing rules.
- Preserve processed Legacy SV when overriding the base slider multiplier.
- Scroll dock tabs with the mouse wheel and simplify General import settings.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.2.0/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
