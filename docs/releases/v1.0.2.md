# FruitsAtelier v1.0.2 Beta

## Workspace and editing panels

- Arrange side panels by dragging, grouping and reordering dock tabs. Resize either side, collapse groups, and add or close panels through Layout or a tab's panel checklist. Mapping and Timing layouts are retained independently across launches.
- Edit Song Setup, Stream/Stack and droplet randomization in dock panels. Valid changes apply immediately with undo; graph and snap drags commit on release. Stream/Stack previews appear on the main canvas, with explicit actions to break patterns into separate objects or restore slider and banana-shower output.
- Inspect selected sliders' exported timing, SV, maximum DS and horizontal speed in Slider Inspector. Open conversion actions with a long press or Shift+F; Ctrl+Shift+F focuses Stream/Stack and Ctrl+Shift+M opens merge controls in Inspector.
- Keep project-wide Notes across difficulties and saves. Paste copied object references into Notes and click their timestamp/object links to navigate without editing beatmap content. Notes has independent text undo and redo.

## AiMod and difficulty navigation

- Open Catch AiMod with Ctrl+Shift+A to inspect Compose, Design, Timing, Meta and Mapset findings, including object boundaries, timing, metadata and resource checks. Findings use exported Catch objects and preserve map content and undo history.
- Select and copy report rows, resize or reorder columns, scroll long reports, and navigate to timestamps and affected objects. AiMod is a dockable panel; refresh it after edits and automatically check the newly selected difficulty.
- Start difficulty tabs in ascending No Mod star order, then drag to reorder or pin difficulties ahead of ordinary tabs. Manual order and pins remain for the open project session, and keyboard cycling follows the displayed order.

## Rendering and fixes

- Scale the Windows editor from client resolution using the existing 175% reference layout. Improve background cropping and dim coverage at fractional pixel edges.
- Make whole-object Distance Snap, collinear snapping and object alignment compete against the same pointer position. Preserve fractional fruit-group drag bounds and exact standalone-fruit collinear coordinates.
- Edit an interior Stack fruit's horizontal offset on the canvas while retaining its time, neighbouring fruits and center path, with undo and project persistence.
- Correct placement previews around grouped banana showers, pause playback while holding the transport timeline, and cache visible timeline markers and banana-pattern segments.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.0.2/FruitsAtelier-1.0.2-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
