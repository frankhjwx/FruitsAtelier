## Download

Download **FruitsAtelier-0.8.3-win-x64.zip**, extract the entire archive, and launch **FruitsAtelier.exe**. Keep `Update.exe` and `current/` together. This self-contained Windows x64 package does not require a separate .NET installation.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download and explicitly save and restart. Keep projects and custom skins outside the application's `current/` folder.

If v0.8.2 does not display a check result or download progress, minimize and restore
the window to refresh the update controls. This release fixes that refresh issue.

## Changes

- Application update checks, download progress, and restart readiness now refresh during continuous rendering without minimizing the window.
- **Movement Analysis** adds optional coloured connections for Stand, Walk, Dash, and HDash, with distance-spacing labels. A floating panel shows incoming and outgoing movement and Prev / Next DS. Banana showers break movement connections.
- Edit **Prev DS** for a selected fruit or slider child using a slider or numeric input. Changes preview live, preserve the object's time and original side, and support undo. Hold Shift for fine slider adjustments; a bright ring identifies the selected slider tick.
- Movement labels stay at fixed connection midpoints while scrolling and remain visible independently of skin sprite padding. Dense intervals omit labels to limit overlap.
- The canvas toolbar exposes **Slider Path** and **Movement Analysis** toggles. Clicking blank canvas space preserves playback position.
- Settings now has a category sidebar and detail panel, opens from both Library and Editor, and returns to the originating screen. **Apply** stays in the current category and is enabled only while unapplied changes exist.
- **Appearance → Romanised artist / title** defaults to On. Turning it off prefers Unicode metadata, with fallback when either spelling is missing.
- **View → Volume** opens a compact editor dialog for master, music, and hitsound volume. Changes take effect immediately and persist when the slider is released; playback continues while adjusting.
- Drop `.osz` beatmaps or `.osk` skins into the Library to import them into the workspace without writing to osu! Songs.
- Library entries outside osu! Songs have a distinct background and marker. Existing source or export files in the configured Songs directory determine presence; entries already in Songs retain their usual appearance.
- Saving a project outside Songs saves the workspace first, then offers an optional Songs export when Songs is configured. Keeping the project in the workspace or cancelling export preserves the local save. The unsupported **Save Project As** entry and shortcut have been removed.

## Update packages

The `.nupkg` and `releases.win-x64.json` assets are used by the updater. For manual installation, use the ZIP; its `.sha256` file verifies the download. The fixed `FruitsAtelier-win-x64.zip` asset also points to this release for website downloads.
