# FruitsAtelier v1.4.7

This release improves Hitsounding movement, navigation and sample placement.

## What's new

- **Group movement previews:** move selected Notes, additions and SB sounds with translucent destination ghosts while keeping the originals visible. Selected addition groups can be dragged in either Select or Draw mode. Release commits one undoable move; Escape cancels.
- **Hitsounding navigation:** use Mapping-style keyboard and wheel navigation, middle-drag panning, Ctrl+wheel Snap changes and pointer-anchored zoom. Navigate during a drag or marquee, or hold the pointer at a lane edge to scroll. J/K nudges the active selection by one Snap step.
- **Placement controls:** Sampleset and Additions define new-note and first-addition defaults. Shift+Q/W/E/R and Ctrl+Q/W/E/R select their banks, with hover hints reflecting custom bindings. Left-side bank buttons and Q/A/S/D apply to selections; addition toggles can be assigned in Key Bindings.

## Fixes & improvements

- **Preserved sample banks:** placing another addition keeps the note's existing shared addition bank and Normal bank. Auto overrides remain valid when saving and reopening projects and continue to follow timing changes.
- **Complete group moves:** addition groups move only when every sound has a destination fruit event, avoiding partial moves.
- **Unavailable samples:** missing, unreadable, malformed and oversized audio files are skipped during playback. Failed auditions and library operations no longer interrupt editing with modal errors, and unavailable library folders fall back to an accessible parent.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.7/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
