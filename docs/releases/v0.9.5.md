# FruitsAtelier v0.9.5

## Project creation and version history

- Drop an MP3 onto the Library or editor to create a project with a song title, artist, mapper and difficulty name. Audio is copied into the workspace, with an option to also create a linked Catch difficulty in osu! Songs.
- Browse retained project versions through **Edit → Version history…**, compare individual difficulties and restore earlier content, including deleted difficulties.
- Recovery history uses verified Brotli compression and retains up to 100 rounds per set. Existing uncompressed history remains readable and is compressed gradually while the library is idle.

## Synchronization and timing

- Synchronization review separates changes into category tabs, shows explicit object differences and supports choosing resolutions from highlighted object ranges. Historical comparisons use the same categorized view.
- Saves automatically write new FA edits to linked osu! difficulties against their resolved versions, including timing, breaks and bookmarks. Metadata changes rename linked beatmap files.
- **Override SV** in the Timing panel allows changing base slider velocity while preserving converted geometry and NM/HR playback. Continuous adjustments validate in the background after one second of idle time and commit as one undo step.
- Improved handling of fractional break boundaries and external osu! zoom changes, and corrected VBR MP3 timeline alignment.

## Editing and preview improvements

- Refined Stream and Stack controls and conversion, with previews following the editor's AR time scale and shared fruit-breaking behavior.
- Added **Edit → AiMod** overlap checks for the current difficulty.
- Improved responsiveness during saving, synchronization, fruit placement and slider drafting by reusing conversion results and keeping completed-map validation in the background.
- Corrected preview scrolling, kept edge objects visible, added testplay volume arrow shortcuts and displayed progress while synchronization blocks file actions.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.5/FruitsAtelier-0.9.5-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
