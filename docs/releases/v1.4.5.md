# FruitsAtelier v1.4.5

This release adds manual refinement for background colour palettes.

## What's new

- **Fine-tune background colours:** select a generated swatch and pick its colour directly from the background image, with a magnifier while pressing or dragging. Review per-colour luminance warnings before keeping changes, restore the generated recommendations at any time, then apply the palette to the current difficulty in one undo step.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.5/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
