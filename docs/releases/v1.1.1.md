# FruitsAtelier v1.1.1 Hotfix

## Fixes and improvements

- Restore osu!-compatible sample bank shortcuts in both editing modes: **Shift+Q/W/E/R** selects the normal sampleset and **Ctrl+Q/W/E/R** selects the additions sampleset, for selected objects or new placement.
- Fix empty optional slider sample fields in mixed editing exports while preserving explicit edge sounds and sample banks.
- Save the current difficulty in the background without rewriting unchanged difficulties in the set. Keep editing responsive while preserving linked exports, undo history and interrupted-save recovery.
- Keep automatic editing and saving progress unobtrusive. Show a wait dialog when an action must wait for ongoing work.
- Speed up missing linked-map discovery and allow navigation or closing to cancel a read-only search when no requested save depends on it.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.1.1/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
