## Download

Download **FruitsAtelier-0.8.2-win-x64.zip**, extract the entire archive, and launch **FruitsAtelier.exe**. Keep `Update.exe` and `current/` together. This self-contained Windows x64 package does not require a separate .NET installation.

Existing updater-enabled installations can use **Library → Settings → Application updates → Check for updates**, then **Download update** and **Save and restart to update**. Older packages without an updater require one manual ZIP download.

This replaces the initial v0.8.2 package. If you already installed that package, download this replacement ZIP and extract it into a new folder: same-version replacements are not offered by the updater. Keep your existing workspace and preferences.

## Changes

- Automatic update checks run on every startup when enabled, including when a previous check happened the same day. Opening the update page also checks immediately when no update is already available.
- New updates display a clickable notification in both the library and editor. The update page keeps a separate **Check for updates** button alongside the download or restart action. Manual checks work with automatic checks disabled and can retry immediately after a network failure.
- Update checking and downloading run in the background. A failure to save the last-check timestamp no longer prevents checking. Previously downloaded updates remain available if a later check fails; installation still requires explicit **Save and restart to update**.
- The canvas and object timeline use osu!-style beat-snap colors. Full beats, halves and thirds have stronger lines; measure boundaries follow the timing point's time signature and offset.
- Each wheel notch moves one current snap subdivision while paused, or one full beat during playback. Off-grid positions move to the adjacent grid line, including across BPM changes. Canvas scrolling moves the view and playhead together.
- Fruit and FSlider placement previews calculate incoming and outgoing hyperdash markers before placement is confirmed.
- Playback supports **10%, 25%, 50%, 75%, 100%, and 150%** speed while preserving music pitch. Hitsounds retain their original pitch.
- Box selection on the canvas and object timeline keeps its starting map timestamp fixed during playback, so the selection grows as the view advances.
- FSlider export handles nearby SV reset points without falsely rejecting compatible slider timing. Incompatible timing still reports the conflicting timestamps.
- Missing optional videos, storyboards, backgrounds, and samples no longer leave persistent missing-resource warnings. Missing required project/audio resources remain visible.
- Native file dialogs suspend conflicting redraws. The editor recovers from Direct2D paint failures while retaining the open document.
- Newly opened maps start at 0 ms from the first frame. The total duration and overview wait for audio loading to finish instead of briefly showing provisional values. Returning to an open difficulty retains its playback position.

## Update packages

The `.nupkg` and `releases.win-x64.json` assets are used by the updater. For manual installation, use the ZIP; the `.sha256` file verifies that ZIP. Keep projects and custom skins outside the application `current/` folder, which is replaced during updates.

The fixed `FruitsAtelier-win-x64.zip` download points to the latest stable release and is also used by the website.
