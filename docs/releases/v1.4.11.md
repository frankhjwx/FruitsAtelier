# FruitsAtelier v1.4.11

This release improves storyboard hitsound filenames and fixes slider conversion and export timing.

## What's new

- **Readable storyboard audio filenames.** Newly imported audio is saved in `SBHitsounds` using its original filename. Different audio with the same name receives a numeric suffix, such as `cheer-2.wav`. Existing file references remain unchanged.

## Fixes & improvements

- Storyboard sound placement, paste and movement use integer milliseconds, including shared `.osb` edits. Repeated edits retain selection, and `.osu` export normalizes retained fractional sample timestamps.
- Fractional green timing points in the same millisecond as a slider head preserve its required SV without changing sample, volume or effect fields. Later sliders regain the original SV when needed.
- Sliders extending beyond the saved workspace duration remain convertible. Moving or deleting Legacy sliders no longer fails because another slider extends beyond that duration.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.11/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Use **Settings → Application updates → Check for updates** in an updater-enabled installation, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. Use the ZIP and its `.sha256` checksum for manual installation.

Mapset Verifier's corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip`.
