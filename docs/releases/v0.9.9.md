# FruitsAtelier v0.9.9

## Editing and export

- Improve FSlider placement in Legacy and Pen modes: keep the draft head visible from the first anchor, refresh the completed preview before background validation, and support New Combo from the blank-canvas context menu.
- Apply distance snapping to Pen slider heads and improve dragging, navigation, and slider control selection.
- Match slider droplet randomization to osu!stable and align fractional FSlider tiny events with exported head times.
- Normalize exported `.osu` section and field order, avoid unused leading SV compensation, and reject timing SV changes that cannot be exported with a base-SV override.
- Adjusting slider repeats no longer shows sample-adjustment notices.

## Library and workflow

- Automatically order difficulty tabs by ascending star rating and refresh library ratings after saves.
- Prompt before the first save of an imported Songs difficulty, remove deleted library entries, and count successfully indexed maps in scan progress.
- Press **F12** to copy an editor or paused-testplay screenshot to the clipboard.
- Find the project website, GitHub page, Discord community, and Yumeno Himiko's osu! profile in **Settings → Application updates**.

## Testplay

- Hold Quick Retry for 250 ms to restart, with dimming, the pause loop during the hold, and a retry click.
- All retries use the same reaction countdown as Continue. Improve held-retry audio and shortcut handling with an active IME.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.9/FruitsAtelier-0.9.9-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
