# FruitsAtelier v0.9.3

## What's new

- **Stack editing:** reshape stack envelopes, move individual fruits, edit time percentages and pixel positions, and undo changes within the stack draft before applying it.
- **Object tools:** break slider streams into fruits, clear selected internal slider anchors, and merge consecutive objects with a preview and undo support.
- **Timing controls:** improved Snap wheel behavior, section and whole-map timing operations, and timing-point editing controls.
- **Background and testplay:** skinned pause and skip controls, background dimming with a draggable percentage bar, and a persistent **Dim Background** override in View and Settings.
- **Editing preferences:** remember grid snapping, distance snapping, movement analysis and grid level per difficulty, and configure canvas scroll direction in Settings.

## Fixes and improvements

- Slider shape controls can extend beyond the playfield, while whole-object movement retains its placement rules.
- Synchronization reviews complete beatmap sections as bounded text, ignores osu! save-only changes, and handles timing edits around generated slider velocity points.
- Corrected authored distance readouts, timeline skin colours, repeated-slider compensation targets and downstream tiny-droplet compensation after fractional banana exports.
- Reduced placement-preview timing work and bounded native rendering caches.
- Grouped View controls with separators and removed preview debug curves. Background preferences can be applied while library scans or searches run.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.3/FruitsAtelier-0.9.3-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
