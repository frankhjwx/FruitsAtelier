# FruitsAtelier v1.4.8

This release makes Library exit safer, remembers Object Snap settings across difficulties, and improves macOS development builds.

## What's new

- **Library exit confirmation:** pressing Esc in the Library main view now asks before closing. Choose Exit to quit; Cancel, Enter or Esc keeps the application open. Active menus, fields and subpages are dismissed first.
- **Global Object Snap preferences:** the enabled switch and earlier/later search ranges now apply across difficulties and survive restarts on this computer. Existing per-difficulty values are ignored. Without saved global settings, Object Snap starts disabled with a two-beat earlier and one-beat later search range.

## Fixes & improvements

- **macOS rendering:** prevent nested render calls during workspace opening, focus changes and error recovery.
- **macOS audio:** use SoundTouch-prepared music PCM and a shared host-clock origin for music and hitsounds across playback speeds. Seek, pause/resume and speed changes restart buffered playback at the retained position.
- **macOS sample auditions:** preserve short sample attacks, prepare missing panel samples asynchronously, and cancel pending playback when stopping or replacing the project.

macOS changes apply to source builds; this release distributes the Windows x64 portable package.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.8/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
