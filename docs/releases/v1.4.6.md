# FruitsAtelier v1.4.6

This release fixes Kiai editing and improves selection feedback in Hitsounding.

## Fixes & improvements

- **Kiai on red timing points:** toggle Kiai on red points or mixed red/green selections without inserting extra green points. Other timing properties and effects are preserved, with undo/redo support.
- **Hitsounding selection:** start a selection rectangle in a locked track and select sounds in unlocked tracks. Locked tracks remain protected.
- **Clearer visual feedback:** locked tracks use a pale red background. Selecting sound tags leaves the Notes graphics unhighlighted.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.6/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
