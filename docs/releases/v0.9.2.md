# FruitsAtelier v0.9.2

## What's new

- **Workspace synchronization:** linked osu! files are monitored for external changes, including renamed or missing sources and new difficulties. Review conflicting object changes on aligned map canvases and choose metadata changes row by row while preserving editable slider controls.
- **Storage management:** manage workspace history and caches from Settings, and delete local project versions from the Library while retaining a recovery copy and the original source beatmaps.
- **Editing tools:** configurable collinear distance snapping helps align objects with their neighbours. Clear internal FSlider nodes across the active difficulty, inspect tiny-droplet coordinates and movement, and choose whether tiny droplets participate in movement analysis.
- **Audio and testplay:** choose whether to use skin sound samples in Audio settings. Autoplay supports playback-speed switching, and testplay remains active through speed changes.

## Fixes and improvements

- Switching difficulties preserves the current timeline position during playback and while paused.
- Library categories retain their loaded views, refresh difficulties from live sources, and show missing references while discovery runs in the background. Library indexing includes only Catch beatmaps.
- Synchronization ignores osu! save-only slider formatting changes and keeps conflict choices reviewable as external files change.
- Improved selected-object deletion, distance-snap controls and readouts, mapping shortcuts, selection feedback, and grouped context menus.
- Preserved partial tiny-droplet compensation when full compensation cannot fit the slider path, and raised the project file size limit to 128 MiB.
- Reduced beat-grid allocations during playback.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.2/FruitsAtelier-0.9.2-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
