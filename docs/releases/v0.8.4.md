## Download

Download **FruitsAtelier-0.8.4-win-x64.zip**, extract the entire archive, and launch **FruitsAtelier.exe**. Keep `Update.exe` and `current/` together. This self-contained Windows x64 package does not require a separate .NET installation.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download and save and restart. Keep projects and custom skins outside the application's `current/` folder.

## Changes

- **Multiple Distance Snap presets:** configure up to eight DS values per difficulty. All values participate in snapping simultaneously, choosing the closest valid position. Zero DS is always available without using a preset slot; new and previously unconfigured maps start with an empty list.
- Hover **Distance Snap** to open **Configure DS…**. A coloured Stand / Walk / Dash / HDash reference shows movement thresholds. Click the arrow row to add a value at that position, use **Add** for 0 DS, drag arrows to adjust, and right-click to remove. Dragging uses 0.1 steps, or 0.01 with Shift. Apply saves the list as one undoable change.
- **Four-beat pattern preview:** place and remove fruits on a temporary canvas, including the closing beat. The Snap slider uses the editor's subdivisions; red fruits indicate hyperdash starts. **Reset** clears the preview, and **Show DS**, off by default, displays coloured spacing labels between fruits. Labels turn red when their DS no longer matches the configured values. Preview fruits are not added to the map.
- Distance snapping and DS readouts now share the base slider-velocity reference and ignore inherited green-point SV. Custom presets replace the former single-multiplier Alt control; Alt still temporarily inverts Distance Snap. Presets are saved in the project, not exported to `.osu` files.
- **Direct X editing:** click the X row in the compact movement panel to enter a whole-number horizontal coordinate for a selected fruit or slider child, with live preview and undo support.
- Marquee selection supports mouse-wheel navigation and automatic scrolling near the canvas or object timeline edges.
- While paused, drag the play line's yellow handle to change its height without changing the current time. Playback keeps the chosen height for the editor session.
- Fixed Windows pause/resume position drift caused by in-flight audio clock updates. Playback resumes from the captured pause position.
- Improved Windows audio continuity at playback speeds of 25% and below.

## Update packages

The `.nupkg` and `releases.win-x64.json` assets are used by the updater. For manual installation, use the ZIP; its `.sha256` file verifies the download. The fixed `FruitsAtelier-win-x64.zip` asset also points to this release for website downloads.
