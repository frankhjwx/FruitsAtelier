# FruitsAtelier v1.3.3

## Fixes and improvements

- **Cross-canvas editing:** move, mirror, copy, cut, paste and change repeats across Catch and osu! canvases while preserving slider types. Shape edits offer conversion, switching to the matching canvas, or cancellation.
- **Movement Analysis label cutoff:** customize the interval below which DS and speed labels are hidden in Settings → Mapping Canvas, with presets and a Reset control.

- Match osu!stable slider droplet timing and TinyDroplet compensation more closely.
- Preserve rounded slider event times and neighbouring positions during isolated edits, including after saving and reopening projects.
- Restore Ctrl+plus/minus repeat-count editing when a slider is selected; with no slider selected, these shortcuts adjust UI scale.
- Refresh the Recent library after opening maps and preserve the intended map when double-clicking entries.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.3.3/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
