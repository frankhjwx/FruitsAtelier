# FruitsAtelier v0.9.8

## Hitsound Copier (Beta)

- Open **Timing → Hitsound Copier (Beta)** to copy sounds from an external osu!standard or Catch map, another difficulty in the current set, or clear existing sounds.
- Match playable events within 2 ms when red timing sections agree. Copy sample bank, index and volume changes while preserving the target's SV and Kiai.
- Apply to the current difficulty or all target difficulties, overwriting with undo support or creating named copies. Preview resource changes before applying; shared files are retained and deleted files are backed up.
- Copied sounds in preview and testplay resolve against the current timing settings. Selecting a slider head or tail in the object timeline selects that edge for hitsound editing.

## Editing and Timing

- Improve slider anchor visibility, selected endpoint dragging, and control selection when stream fruits overlap. Edit isolated stream fruits and drag stream heads and tails; drags inside selection boxes move the parent group.
- Add a canvas toolbar toggle for selection rectangles and fit toolbar labels across languages.
- Refine Timing pause and tap controls. The tenth tap fits BPM and offset together; later taps continue refining both. Timing preview lines span the full canvas.
- Improve editor navigation and previous-save restoration. **Ctrl+L** restores the active difficulty's previous saved version after confirmation, with undo support.
- Preserve separate romanised artist and title fields for audio projects, correct project initialization and integer timing, and improve Songs exports.

## Testplay and audio diagnostics

- Testplay opening preparation provides at least two seconds of map time before early notes, respecting longer lead-in settings. Movement and dashing work during preparation, and music begins continuously at zero on the same audio clock. Retry retains preparation.
- Configure audio diagnostics and output profiles in **Settings → Audio**. Applying changed diagnostic options restarts the application and restores the Audio settings position and active editor state.
- Export bounded diagnostic reports and mark audio issues without including map files.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.8/FruitsAtelier-0.9.8-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
