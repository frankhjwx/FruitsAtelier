# FruitsAtelier v1.3.0

## What's new

- **Video and storyboard playback:** preview beatmap videos and storyboards in sync with music, including storyboard samples, animations and gameplay triggers. The persistent **Enable Video/Storyboard** preference controls visuals across the editor and Testplay.
- **Independent SV controls:** inspect export-equivalent SV timing rows and control independent SV visibility and editing locks from the Timing panel.
- **Expanded user manual:** feature references, guided editing tutorials and updated keyboard shortcuts cover the current editor workflows.

## Fixes and improvements

- Preserve slider duration and extents when editing timing near adjacent BPM and SV boundaries.
- Merge overlapping breaks and restore affected break fragments after removing notes.
- Make one-millisecond timing corrections explicit in Mapset Verifier reports.
- Improve storyboard loading, compressed macro handling, seeking and scene reuse, and retain shared video decoding while a viewport still needs it.
- Reduce editing overhead and the size of bundled music and PNG resources.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.3.0/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
