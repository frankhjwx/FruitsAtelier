# FruitsAtelier v1.4.1

This release adds editable bookmark colors and intervals, expands Hitsounding workflows across difficulties, and improves sample inheritance and editing feedback.

## What's new

- **Dockable Bookmarks panel:** edit timestamps, colors and interval displays, jump to bookmarks, and add or remove entries with undo/redo. Colors and interval settings are saved per difficulty in `.catchproj`; `.osu` exports retain bookmark timestamps.
- **Shared mapset Hitsounding workflow:** retain the active workspace and hitsound clipboard when switching difficulties. Copy sounds in one difficulty and paste them into another.
- **Spinner end samples:** edit and preview Normal, Whistle, Finish and Clap samples at banana-shower ends, with settings preserved on export.
- **Faster Hitsounding editing:** click empty addition slots to place sounds, drag to marquee-select, and use Q to cycle sample banks. Sampleset and Additions selectors apply to selected events in one undo step. Kiai intervals and starred timing labels make Kiai sections easier to identify.
- **Explicit Song Setup synchronization:** edit General metadata per difficulty, then use the synchronization action to copy metadata, colors and supported Design settings across the mapset.
- **Timing clipboard menus:** copy selected timing rows or paste valid timing lines from context menus, with fading copy confirmation.

## Fixes and improvements

- Preserve Normal sample banks when placing additions, and retain timing sample-index inheritance during hitsound transfers, playback and export.
- Correct inherited volume handling in Hitsound Copier and limit transfer confirmation to differing source/target timing sample indices.
- Improve Hitsounding placement, selection and play-line input priority; dragging from an empty addition slot selects without adding sounds.
- Clear inherited break periods when creating a blank difficulty.
- Correct legacy slider draft distance and movement readouts.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.4.1/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
