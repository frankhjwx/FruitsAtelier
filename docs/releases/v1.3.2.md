# FruitsAtelier v1.3.2

## What's new

- **Seven editor themes:** choose Graphite, Studio, Black Pearl, Midnight, Forest, Rose or Slate in Settings → Appearance, with live preview and matching Windows 11 title bars. Theme, skin and display controls are grouped together.
- **Pattern clipboard sharing:** copy and paste compact pattern geometry text to share patterns between editors.
- **Movable canvas controls:** Background Dim, Video/Storyboard and Discussion annotations share a compact panel that can be dragged and resized from its corners. Its position and scale are remembered.

## Fixes and improvements

- Preserve native slider geometry with default droplet randomization, align exported slider heads with effective SV timing, and fill empty slider edge samples for osu!stable export.
- Copy the playhead timestamp with Ctrl+C in Select mode when no objects are selected.
- Prioritize objects closest to the current time when drawing and selecting overlapping objects on the osu! canvas.
- Keep advanced droplet parameters in a collapsed section to reduce Inspector clutter.
- Move the bookmark toolbar horizontally and fade it in between 250 and 500 ms of hovering over the overview.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.3.2/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
