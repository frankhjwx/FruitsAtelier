# FruitsAtelier v1.1.0

## osu! editing canvas

- Switch to the osu! canvas to edit standard playfield geometry alongside the Catch timeline and preview. Import Mode=0 maps and export their Catch conversion.
- Place circles, sliders and spinners, edit native slider control points, and use circular arcs for three-point slider drafts. Slider length snapping and timeline previews follow the active timing and distance settings.
- Move selected objects with Distance Snap and object snapping. Refined selection, combo previews, tool icons and timeline zoom make dense patterns easier to inspect.
- Set a remembered default SV for new osu! sliders and read movement spacing in DS units.

## Legacy slider editing

- Edit the original Legacy slider controls and switch between original and droplet-processed paths in Slider Inspector.
- Set independent Legacy slider SV, with Shift duration-locked editing, project persistence and compatible timing export.
- Apply droplet processing to hand-drawn Legacy sliders. Remember global Droplet Settings and the preferred mode for new sliders while retaining existing project values.

## Performance and compatibility

- Reduce dense-map playback work with cached slider rendering, bounded texture storage and smoother raster replacements across display DPI settings.
- Compact large imported slider snapshots and reuse geometry and hitsound data. Improve support for dense XNOR slider maps and legacy timing, including sub-millisecond beat lengths.
- Load and refresh the Library incrementally, retaining the active difficulty during automatic synchronization.

## Interface and fixes

- Use **Ctrl+= / Ctrl+-**, **Ctrl+Shift+=** or **Ctrl+keypad plus/minus** to adjust UI scale, including with selected sliders. Change slider repeats by dragging the object-timeline tail.
- Customize **Settings → Appearance → Selection highlight** for Catch selection rings and boxes, with HEX input and reset. The osu! canvas retains orange selection rings.
- Remember window state, canvas visibility, difficulty snap preferences and global droplet defaults.
- Keep movement and dash keys held when entering or resuming testplay.
- Fix stale slider selections after validation rollback, playback clicks starting drags, narrow-canvas movement bounds and slider texture cache thrashing.
- Preserve independent slider timing when changing base SV, restore slider state when reversing a timeline-tail drag, and reject mixed read-only cuts without disturbing pending edits.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.1.0/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
