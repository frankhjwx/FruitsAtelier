# FruitsAtelier v1.3.5

This release adds Aspire slider BPM multipliers and improves Catch timing, imports, exports and storyboard responsiveness.

## What's new

- **Aspire slider BPM multipliers:** enable the feature in Song Setup → FA Settings → Aspire Features, choose a default for newly drawn sliders, or set a selected slider's multiplier in Slider Inspector. Presets and custom positive values are supported, with generated timing points included in export.

## Fixes and improvements

- **Automatic Catch breaks:** placing, pasting or retiming objects generates breaks in qualifying gaps using osu!'s Catch editor recovery and AR preempt rules. Existing manual break boundaries are retained where applicable, and break changes share the object's undo step.
- **More accurate Catch star ratings:** use exported content and lazer's fractional slider tick times and positions for difficulty calculation.
- **Difficulty imports:** allow independent artist and title metadata, retain project resource paths, and avoid selecting unrelated media with matching filenames.
- **Safer osu! exports:** shorten long generated filenames and mapset folder names deterministically, and reject incompatible destination paths before writing.
- **Clearer slider feedback:** explain constrained event drags and show a bold red warning when movement would exceed the 10x SV limit.
- Preserve the Song Setup category and scroll position when content refreshes.
- Bound storyboard seek preparation and reduce unnecessary texture churn.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.3.5/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
