# FruitsAtelier v1.3.4

This maintenance release focuses on bug fixes and performance improvements.

## Fixes and improvements

- **Smoother difficulty switching:** keep the editor and previous media presentation visible while the next difficulty prepares, reuse unchanged audio, backgrounds, storyboard images and video, and pause playback during the transition.
- **Playback and rendering performance:** reduce autoplay allocations and avoid processing off-screen imported slider bodies and repeats unnecessarily.
- **More reliable error recovery:** keep recovery saving accessible after repeated rendering or background-task failures, preserve committed unsaved edits and retained projects, and prevent reentrant input from interrupting recovery.
- **Bounded diagnostic rendering:** keep very long errors and large resource reports responsive, and limit excessive storyboard expansion.
- Fix crowded discussion annotation layout and reject stale report navigation targets.

## Download

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v1.3.4/FruitsAtelier-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support. Embedded osu! Web requires the Microsoft Edge WebView2 Runtime.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.

The bundled Mapset Verifier uses the editor's .NET runtime. Its complete corresponding source and build materials are provided separately as `FruitsAtelier-MapsetVerifier-v2.1.1-source.zip` in the Release assets; this attachment is not required to run or update the application.
