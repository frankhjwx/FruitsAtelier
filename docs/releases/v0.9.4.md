# FruitsAtelier v0.9.4

## Timing fixes

- Corrected exported object times and generated slider velocity points that could land 1 ms later than osu!stable's integer beat snaps. Export now truncates time toward zero, consistent with MapsetVerifier's practical snapping calculation.
- Beat-grid calculations preserve exact whole-millisecond snap positions, avoiding floating-point errors at integer boundaries.
- Placement previews use the same time quantization as exported objects. Slider span durations and the project's precise authoring times are preserved.

Use this version to export again from your original FruitsAtelier project. Existing exported integer times are preserved on import and are not automatically shifted.

## Other improvements

- The preview shows cached star ratings for NM, EZ and HR.
- Improved localization consistency in preview and difficulty controls.

## Download and update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.9.4/FruitsAtelier-0.9.4-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

The `.nupkg` and `releases.win-x64.json` assets serve in-app updates. For manual installation, use the ZIP; its `.sha256` file verifies the download.
