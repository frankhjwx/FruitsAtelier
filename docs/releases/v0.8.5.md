**v0.8.5 is a substantial editor update**, with a new Song Setup dialog, reworked timelines and break editing, and a configurable Distance Per Beat reference.

## What's new

- **Song Setup:** edit song metadata shared across difficulties, the current difficulty's name and HP/CS/AR/OD, and custom combo colours with a colour picker and HEX input. Changes support undo and are saved in projects and `.osu` exports. The Design tab also stores countdown and presentation options for export; countdown and storyboard effects are not rendered in the editor.
- **Reworked timelines:** the upper object timeline shows combo-coloured objects, clearer slider bodies and reverse arrows, selection outlines, timing markers, and shaded breaks. The bottom overview brings together timing points, bookmarks, Kiai sections, breaks, and the song preview marker, with Play, Pause, Stop, and Testplay controls alongside it.
- **Break editing:** use **Insert Break Time** to add a break in a suitable gap between objects, then drag its edges on the upper timeline to adjust it. Edge dragging follows the current beat Snap and supports undo. Movement Analysis now leaves gaps across breaks.
- **Bookmarks and preview point:** hover over the bottom timeline for bookmark controls. During Testplay, **Ctrl+B** adds a bookmark and **Ctrl+Shift+B** removes a nearby one. Set the song preview point from the Timing menu. A beat-synced Kiai cue is also visible in the editor.
- **Configurable Distance Per Beat (DPB):** set the editor's **1.0x distance reference** in **Configure DS…**, using the movement reference bar or a numeric value. Optional grid snapping helps with drag adjustments.

## Distance Snap users

The eight-preset system introduced in v0.8.4 remains available. Changing DPB rescales the preset multipliers to **preserve their pixel distances**, so the displayed DS numbers can change. Apply saves the reference and presets together per difficulty; Cancel discards the changes.

DPB is an editor-only setting: it does **not** change the beatmap's slider multiplier or existing slider playback, and the override is not exported to `.osu`.

## Fixes & improvements

- Improved Testplay hitsound alignment with music output and corrected hitsound inheritance before the first timing point.
- More consistent text selection, caret movement, and clipboard behaviour across editor fields.
- **V / End** now seeks to the final exported osu! object's end.
- The canvas play line's height is remembered across editor restarts.
- Improved responsiveness on maps with many breaks or large storyboards, and stabilized the Kiai pulse.
- Language selection now lives under **Settings → Appearance**.

## Download / Update

Download the [Windows x64 ZIP](https://github.com/frankhjwx/FruitsAtelier/releases/download/v0.8.5/FruitsAtelier-0.8.5-win-x64.zip), extract the entire archive, and launch **`FruitsAtelier.exe`**. Keep `Update.exe` and `current/` together. The package includes .NET and requires Windows 10/11 x64 with DirectX 11 support.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download, save, and restart. Keep projects and custom skins outside the application's `current/` folder.

**Known update issue:** v0.8.4 may report that it is already up to date because GitHub's public releases list omits v0.8.5's assets. If this happens, download the ZIP above, extract it into a new folder, and launch `FruitsAtelier.exe` there. Keep your existing projects and skins in their current locations.

## Update packages

The `.nupkg` and `releases.win-x64.json` assets are used by the updater. For manual installation, use the ZIP; its `.sha256` file verifies the download. The fixed `FruitsAtelier-win-x64.zip` asset also points to this release for website downloads.
