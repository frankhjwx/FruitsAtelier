## Download

Download **FruitsAtelier-0.8.5-win-x64.zip**, extract the entire archive, and launch **FruitsAtelier.exe**. Keep `Update.exe` and `current/` together. This self-contained Windows x64 package does not require a separate .NET installation.

Existing updater-enabled installations can use **Settings → Application updates → Check for updates**, then download and save and restart. Keep projects and custom skins outside the application's `current/` folder.

## Changes

- **Song Setup:** edit shared metadata, difficulty settings, and combo colours in the editor. Changes participate in undo and persist through project saving and `.osu` export.
- **Timeline editing:** the overview shows combo colours, timing lines, bookmarks, Kiai sections, and break intervals. Adjust break boundaries by dragging them on the upper timeline. A hover toolbar adds, removes, seeks, and resets bookmarks; the Timing menu can set the preview point.
- **Playback controls:** play, pause, stop, and Testplay are available beside the timeline. Testplay supports Ctrl+B for bookmarks. The editor shows a beat-synced Kiai cue during Kiai sections.
- **Distance Per Beat:** configure an editor-only 1.0x distance reference and up to eight Distance Snap presets. Preset pixel distances remain stable when the reference changes. Imported slider playback and the beatmap's slider multiplier are preserved.
- Improved slider and selection rendering on the object timeline, text editing, movement analysis across breaks, hitsound timing, and editor responsiveness on maps with many breaks.

## Update packages

The `.nupkg` and `releases.win-x64.json` assets are used by the updater. For manual installation, use the ZIP; its `.sha256` file verifies the download. The fixed `FruitsAtelier-win-x64.zip` asset also points to this release for website downloads.
