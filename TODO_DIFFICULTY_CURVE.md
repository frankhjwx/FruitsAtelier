# Catch Difficulty Curve

The editor provides an optional whole-map movement-strain sidebar with continuous
playback seeking. It shares the background star-rating calculation and can appear
alongside Catch Preview without changing beatmap content.

See [Editing controls](docs/EDITOR_UI.md) for layout and interaction,
[Catch difficulty](docs/CATCH_DIFFICULTY.md) for sample semantics and caching,
and [Building and testing](docs/TESTING.md) for regression procedures.
