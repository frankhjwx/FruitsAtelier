# Assist toolbar icons

These seven transparent PNG symbols were generated with OpenAI image generation for FruitsAtelier, using `../tools/select.png` as the style reference. They use mint teal, off-white and restrained gold accents.

The shared editor draws the charcoal button, border and localized label. Its 512-unit template matches the left palette: a 480-unit square inset by 16, radius 64, border 8, icon center (256,204), and label top at 76% of the tile. Active symbols render at full opacity; inactive ones at 45%. Text is not baked into these images.

| Asset | Symbol |
| --- | --- |
| new-combo.png | Ringed fruit with sparkles |
| whistle.png | Whistle with sound waves |
| finish.png | Cymbals |
| clap.png | Clapping hands |
| grid-snap.png | Grid and centered fruit |
| distance-snap.png | Fruit endpoints, spacing arrow and musical note |
| lock-notes.png | Fruit and padlock |
